# Industrial Sensor ETL Pipeline

A Python ETL pipeline that reads raw machine sensor data, validates it, converts units, adds engineering features, and loads the result into SQLite with a summary report.

## Problem
Raw sensor data often has inconsistent column names, units in Kelvin, no validation, and no reporting. This pipeline turns it into a clean, analysis-ready dataset.

## What the pipeline does
1. **Extract:** reads the raw CSV (10,000 readings)
2. **Transform:**
   - standardizes column names
   - checks for missing values and duplicates
   - converts temperatures from Kelvin to Celsius
   - adds temperature difference and mechanical power (W) from torque and rpm
   - flags torque outliers using the IQR method
3. **Load:** saves a clean CSV and a SQLite database
4. **Report:** produces a summary by quality type

## Tools
Python, pandas, NumPy, SQLite

## How to run
```
pip install -r requirements.txt
python make_data.py
python etl.py
```

## Note on data
The data is simulated (generated by `make_data.py`) to mirror the structure of the AI4I 2020 predictive maintenance dataset. The pipeline also works on the real dataset: place it in `data/raw/` as `ai4i2020.csv` and run `python etl.py`.
